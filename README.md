# Fynxt Automation

Test automation for Fynxt CRM and CP portals

## Overview

This repository contains automated test suites for the Fynxt CRM (Customer Relationship Management) and CP (Control Panel) portals. Built with TypeScript, it provides comprehensive testing capabilities to ensure reliability and quality across Fynxt applications.

## Technology Stack

- **Language**: TypeScript
- **Primary Focus**: End-to-end and functional testing
- **Platforms Tested**: Fynxt CRM and CP Portals
